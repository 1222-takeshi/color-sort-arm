# color-sort-arm

色で小物を仕分ける6軸ロボットアームです。独立したパン・チルト雲台に載せた
ESP32-CAM が作業領域を見て色ごとに物体を検出し、アームがつかんで色別の
置き場へ運びます。

サーボは Feetech STS3215（7.4V、C001）のシリアルバスサーボで、SO-101
フォロワーの構成に合わせているため、LeRobot のキャリブレーションや
テレオペレーションの資産が使えます。フレームは公式SO-101の印刷データを
FLASHFORGE Adventurer 3（150×150×150 mm）で印刷します。

English README: [README.md](README.md)

## ハードウェア

| 役割 | 部品 |
|---|---|
| 第1〜6軸（ベース、肩、肘、手首ピッチ/ロール、グリッパー） | STS3215（7.4V）×6 |
| バスアダプタ | Waveshare Bus Servo Adapter (A) または相当品 |
| カメラ | ESP32-CAM（OV2640）、9gサーボの雲台に搭載 |
| 制御 | Raspberry Pi Pico（バスアダプタへUART、PCへはUSBシリアル） |
| 電源 | 12V 5Aアダプタ → 降圧で7.4Vを作りサーボバスへ給電 |

## リポジトリ構成

- `software/` - PC側C++17ソフトウェア。逆運動学と平面キャリブレーション
  （依存なしのコア）、HSV色検出（OpenCV、1モジュールに隔離）、サーボ
  ドライバのインターフェースとスタブ実装、ピック＆プレースのシーケンス。
  単体テスト付き
- `cad/` - 参考として残すパラメトリック部品ジェネレータ（アーム本体の
  フレームは公式SO-101データを使用）
- `docs/PLAN.md` - 設計計画、`ROADMAP.md` - 開発ロードマップ
- `CONTRIBUTING.md` - 開発プロセス（ロードマップ → Issue → TDD →
  小さいPR → レビュー → マージ）
